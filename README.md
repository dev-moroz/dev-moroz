## 👨‍💻 About Me

👋 I'm a Frontend Engineer with 7 years of experience building production systems for FinTech and TravelTech.

I turn vague, urgent problems into production systems that keep working without me. I'm happiest on internal products, platform architecture and reusable systems, where the interesting part is the business process behind the UI.

**Core stack:** Vue 2/3 · Nuxt · TypeScript · React · Next.js · Pinia · Node.js / NestJS · Strapi
**Also working with:** Claude Code, MCP, LLM APIs and agentic workflows

### 🚀 What I've shipped
- 🏗️ **Low-code platform with backend-driven UI**: mobile app flows and screens are configured on the backend, and analysts build them without developers. I built the canvas editor as a standalone npm library, reused across 3 projects.
- 🌐 **Shared Nuxt + Strapi platform** powering 4+ client sites: custom plugins, a ready-made core, and docs so new teammates can pick it up quickly.
- 💳 **End-to-end payment flows** for a travel booking platform: 4 payment methods, POS terminals, refunds, voids and split payments.
- ⚙️ **CI/CD from scratch**: automatic deploys on push, down from 20 minutes of manual work.

### 🔨 Currently
- Building an admin panel for an English school (Next.js + NestJS): lesson planning, balances, payments, roles. It's in production, built solo with TDD and AI agents. A public part of the code is coming to this profile soon.
- Running a Proxmox home lab where my side projects live.

### 🔎 Open to
Product companies in Europe with complex frontend, platform or internal-tooling work. Relocation is on the table.
